# Техническое описание механической руки

## 1. Концепция

Механическая рука — это упрощённая модель человеческой кисти с 4 пальцами,
каждый из 3 фаланг. Управление — тросовое: один сервопривод тянет нити,
которые проходят внутри пальцев и сгибают их одновременно.

Такой подход выбран по ряду причин:
- минимальное количество приводов (1 серво на всю кисть)
- простая механика — надёжна и дёшева
- детали легко напечатать на 3D-принтере или вырезать из фанеры
- безопасна: усилие передаётся через нить, нет жёстких зубчатых передач

## 2. Конструкция

### Пальцы
Каждый палец состоит из трёх звеньев (фаланг), соединённых шарнирными осями.
Внутри каждого пальца проходит канал, по которому идёт нить.

### Тросовая система
Нить (леска ~0.5 мм) крепится на кончике пальца, проходит через направляющие
отверстия фаланг и ладони, и выходит к барабану на валу сервопривода.
При намотке нити пальцы сгибаются. При размотке — выпрямляются.

### Возврат
Возврат в исходное положение обеспечивают резиновые ленты,
натянутые по тыльной стороне пальцев. При ослаблении нити
резинки разгибают фаланги обратно.

## 3. Компоненты

| Компонент | Характеристики | Назначение |
|---|---|---|
| Сервопривод MG996R | 11 кг·см / 6В, металл. редуктор | Привод тросов |
| Arduino Uno | — | Получение команды с ПК, ШИМ-сигнал на серво |
| Нить (леска) | d ~0.5 мм | Тросовая передача |
| Резиновые ленты | — | Возврат пальцев |
| Каркас | ABS - пластик | Ладонь и фаланги |

Почему MG996R: пластиковый редуктор срывает зубья под нагрузкой,
металлический держит. Момент 11 кг·см достаточен для уверенного хвата.

## 4. Логика работы

### Сжатие (ON)
1. Пользователь нажимает кнопку ON на сайте
2. Flask-сервер записывает состояние `powered = True`
3. Сервер отправляет команду на Arduino (Serial или HTTP)
4. Arduino подаёт ШИМ-сигнал на серво: поворот вала на +90°
5. Барабан наматывает нити → пальцы сгибаются → кулак сжат

### Разжатие (OFF)
1. Пользователь нажимает кнопку OFF
2. Сервер записывает `powered = False`, отправляет команду
3. Arduino возвращает серво в 0°
4. Барабан разматывает нити → резинки выпрямляют пальцы → кулак разжат

### Схема взаимодействия
```
[Браузер] → POST /api/toggle → [Flask-сервер] → Serial → [Arduino] → ШИМ → [Серво] → [Рука]
```
