## Компоненты
 
### Кнопка питания
Круглая кнопка в левом верхнем углу карточки.
- `ON` → включает систему, меняет текст на `OFF`, подсвечивается зелёным
- `OFF` → выключает систему, возвращает исходное состояние
- Заблокирована во время выполнения команды
### Блок команд
Три кнопки — `Команда 1 / 2 / 3`.
- Неактивны (`disabled`) пока система выключена
- При hover стрелка `→` сдвигается вправо
- Во время выполнения одной команды остальные блокируются
### Строка статуса
Нижняя полоса карточки. Показывает текущее состояние системы и время последнего события.
 
| Ситуация | Текст | Индикатор |
|---|---|---|
| По умолчанию | ожидание | серый |
| Включено | система готова к работе | зелёный |
| Команда запущена | выполняется команда N... | янтарный (мигает) |
| Команда завершена | команда N выполнена | зелёный |
| Выключено | система выключена | оранжевый |
